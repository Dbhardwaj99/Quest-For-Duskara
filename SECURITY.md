# Security Policy

Quest for Duskara is a single-player game that runs offline inside the macOS App Sandbox. If you find a way it could put a player's data or Mac at risk, please tell me privately.

## Supported versions

Fixes land on `main` and ship in the next release. Older releases don't receive patches.

## Reporting a vulnerability

Please don't open a public issue for security problems. Email divynshh@gmail.com instead.

Include what you found, how to reproduce it, and the release or commit you tested. I'll reply as soon as I can and keep you updated until it's fixed.
